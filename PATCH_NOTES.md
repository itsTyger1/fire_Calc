# FIRE Projector patch notes

This history is compiled from the project’s Git commits and published GitHub Releases, from the first repository commit on September 4, 2026. It records development milestones as well as versioned releases. The repository contains published releases for v1.2.1, v1.2.2, v1.2.4, and v1.2.5; no v1.2.3 release or tag was found in the available history.

## v1.2.6 — September 2026

- Added a Coast FIRE result when the FIRE portfolio is below its target at the selected retirement age.
- Checks whether the current portfolio can fund the annual spending goal from the selected retirement age through age 100, assuming contributions stop. Uses the scenario’s returns, spending, and scheduled Roth transfers.
- Added regression coverage for contribution exclusion, scenario spending, nominal inflation, and the age-100 horizon.

## v1.2.5 — September 2026

- Added Roth account rollover and conversion planning, including backdoor Roth, mega-backdoor, Roth 401(k), taxable conversion amounts, tax funding, transfer schedules, and Roth access tracking.
- Fixed the projection chart’s target-crossing marker and the early-retirement bridge calculation.
- Simplified the budget page and improved rollover and projection guidance.
- Displayed the app version in the desktop UI.

## v1.2.4 — September 2026

- Added desktop smoke-test coverage for the native Load IPC path.
- Continued the change that stores named desktop plans in the app’s user-data folder.

## v1.2.3 — No release found

No v1.2.3 tag or published release appears in the available Git or GitHub release history.

## v1.2.2 — September 2026

- Replaced the desktop save flow with the native file dialog and confirmed the saved file’s location.
- Improved save cancellation and error handling, and covered these paths in desktop tests.

## v1.2.1 — September 2026

- Introduced automatic Windows desktop release builds and publishing from version tags.
- Added in-app update checks, installer downloads, and launch handling, with tests for updater and installer outcomes.

## Earlier development milestones

### September 17, 2026 — Roth rollover support and planning fixes

- Added rollover and conversion scenarios, including after-tax 401(k) mega-backdoor transfers, Roth 401(k) transfers, recurring transfers, contribution basis, conversion lots, and estimated conversion tax.
- Added Roth access and early-retirement bridge tracking for contribution basis and conversion waiting periods.
- Fixed the chart crossing marker and bridge math; simplified the budget page.
- Updated release automation and desktop smoke coverage.

### September 8, 2026 — Named local plans and desktop save improvements

- Added named plan snapshots and Load support.
- Added the Windows Save As flow, user-selected save locations, path confirmation, and save error handling.
- Moved desktop plan files into the application’s writable user-data location.

### September 7–8, 2026 — Results, assumptions, and update experience

- Added retirement drawdown projections, depletion estimates, withdrawal shortfalls, and an early-retirement bridge estimate.
- Expanded scenario comparisons, return assumptions, required-contribution calculations, and sensitivity analysis.
- Improved projection phase explanations, chart tooltips, status labels, and updater experience.
- Added development refresh support and the first automatic desktop update workflow.

### September 5, 2026 — Desktop app and consolidated planner

- Converted the calculator into a Windows Electron desktop application while preserving local plan storage.
- Consolidated plan, monthly budget, account, and contribution-phase inputs.
- Added phase-aware budgeting and fixed cash-savings budget calculations.
- Pinned dependencies and added desktop UI smoke tests and build cleanup scripts.

### September 4, 2026 — Initial FIRE projection calculator

- Created the local-first React, TypeScript, and Vite calculator with account projections and scenario planning.
- Established monthly compounding, real-dollar and nominal-dollar projections, and required-contribution calculations.
- Added local browser persistence, import/export, and calculation tests.

### Repository history notes

- The source history includes intermediate snapshot and merge commits used while synchronizing the repository; these do not describe separate user-facing features.
- Published desktop installers are generated by the GitHub Actions workflow after it verifies the version tag matches the package and current `main` commit.
